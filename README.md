# Crosspost

Write a post once, then copy or open it on each platform: Bluesky, Threads, LinkedIn, Twitter, Facebook and Instagram. Crosspost counts characters the way each platform does, splits long posts into threads, and opens each platform with your text filled in where it can.

There are no accounts or sign-ins. Your draft and preferences stay in your browser.

## Develop

```bash
bun install
bun run dev
```

`bun run build` writes the static site to `out/`. Pushing to `main` publishes it to GitHub Pages.
